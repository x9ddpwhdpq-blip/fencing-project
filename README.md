# Генератор индивидуальных разминочных комплексов для фехтовальщиков

Веб-приложение для создания персонализированных разминочных комплексов на основе научного исследования взаимосвязи между эффективностью разминки и показателями повышения пульса у фехтовальщиков.

## 📋 Описание проекта

Система анализирует индивидуальные особенности спортсмена (вид оружия, уровень подготовки, травмы, тип сессии) и подбирает наиболее эффективные упражнения из базы данных, исключая неподходящие и ранжируя по эффективности на основе экспериментальных данных.

### Основные возможности:

- ✅ Персонализированный подбор упражнений на основе профиля спортсмена
- ✅ Учет противопоказаний и травм
- ✅ Ранжирование по эффективности (пульс)
- ✅ Балансировка комплекса по категориям упражнений
- ✅ Адаптация под тип сессии (соревнования/тренировка/восстановление)
- ✅ Красивый и удобный веб-интерфейс

## 🔧 Как это работает

### Алгоритм генерации комплекса:

1. **Сбор данных** - пользователь заполняет анкету с информацией о себе
2. **Фильтрация** - система исключает упражнения с противопоказаниями
3. **Ранжирование** - упражнения сортируются по эффективности
4. **Подбор** - выбираются упражнения в рамках доступного времени
5. **Балансировка** - комплекс дополняется упражнениями из обязательных категорий
6. **Формирование результата** - генерируется персонализированный комплекс с рекомендациями

### Формула эффективности:

```
итоговый_балл = базовая_эффективность + комбинированный_балл + бонусы - штрафы
```

Где:
- **базовая_эффективность** = `effectiveness_score` (из эксперимента)
- **комбинированный_балл** = расчет на основе `hr_increase`
- **бонусы** = за соответствие виду оружия, типу сессии, приоритету
- **штрафы** = за несоответствие параметрам

Подробнее см. `PLAN.md`

## 📊 База данных упражнений

База данных (`exercises.json`) содержит информацию о каждом упражнении:

- Название и описание
- Техника выполнения
- Показатели эффективности (из эксперимента):
  - `hr_increase` - увеличение пульса
  - `effectiveness_score` - общий балл эффективности
- Параметры фильтрации:
  - `suitable_for` - подходящие виды оружия
  - `contraindications` - противопоказания
  - `skill_level` - подходящие уровни подготовки
  - `intensity` - интенсивность упражнения
  - `session_type_suitable` - подходящие типы сессий

## 🎯 Использование

1. Заполните анкету на главной странице:
   - Выберите вид оружия
   - Укажите уровень подготовки
   - Выберите цель сессии
   - Установите время на разминку
   - Отметьте имеющиеся травмы (если есть)

2. Нажмите "Сгенерировать разминочный комплекс"

3. Система проанализирует ваши данные и создаст персонализированный комплекс

4. Изучите результат:
   - Список упражнений с описанием и техникой
   - Статистика комплекса
   - Персональные рекомендации

## 📝 API Endpoints

### `POST /api/generate`

Генерация разминочного комплекса.

**Запрос:**
```json
{
  "weapon": "foil",
  "skill_level": "intermediate",
  "session_type": "competition",
  "available_time": 15,
  "injuries": ["knee_injury"],
  "age": 20,
  "height": 175,
  "weight": 70,
  "gender": "male"
}
```

**Ответ:**
```json
{
  "status": "success",
  "athlete_profile": {...},
  "warmup_complex": {
    "total_duration": 14,
    "exercises": [...],
    "statistics": {...},
    "recommendations": [...]
  }
}
```

### `GET /api/exercises`

Получение списка всех упражнений из базы данных.

## 🛠️ Разработка

### Добавление новых упражнений

Отредактируйте файл `exercises.json` и добавьте новое упражнение в массив `exercises`:

```json
{
  "id": 11,
  "name": "Название упражнения",
  "category": "aerobic",
  "subcategory": "...",
  "duration": 5,
  "description": "...",
  "technique": "...",
  "effectiveness_score": 8.0,
  "spO2_change": -1.5,
  "hr_increase": 50,
  "suitable_for": ["foil", "sabre", "epee"],
  "contraindications": [],
  "skill_level": ["beginner", "intermediate"],
  "intensity": "medium",
  "priority": 2,
  "session_type_suitable": ["competition", "training"]
}
```

### Модификация алгоритма

Основная логика находится в файле `warmup_generator.py`:

- `filter_exercises()` - фильтрация упражнений
- `calculate_effectiveness()` - расчет эффективности
- `rank_exercises()` - ранжирование
- `generate_complex()` - формирование комплекса

## ⚠️ Важные замечания

- Система не заменяет консультацию с тренером или врачом
- При наличии серьезных травм обязательно проконсультируйтесь со специалистом
- Результаты основаны на экспериментальных данных и могут требовать корректировки
- При возникновении боли во время выполнения упражнений немедленно прекратите их выполнение
