# fencing-project
Система использует результаты экспериментального исследования, проведенного с фехтовальщиками разного уровня. Для каждого упражнения было измерено увеличение пульса (HR) и сформирована субъективная оценка эффективности. Алгоритм анализирует ваши индивидуальные особенности и подбирает наиболее эффективные упражнения, исключая противопоказания.
